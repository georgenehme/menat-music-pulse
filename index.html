GO LIVE WITH MENAT MUSIC PULSE

Activate your daily radar

This static website can be deployed to a public URL from a private GitHub repository. The included GitHub Action checks Apple Music feeds and attempts Kworb Spotify and weekly YouTube pages while honoring robots rules. Partner charts can be imported from authorized CSV exports.

01Upload to a private GitHub repository with the .github/workflows directory included.
02Allow Actions write permissions, then run the workflow once to build the baseline.
03Connect the private GitHub repository to Cloudflare Pages; set Build command to python3 scripts/build_site.py and Output directory to dist.
04Add chart alert secrets only if needed. Connect the MailerLite embedded form to collect confirmed newsletter subscribers. Weekly email sends require a newsletter provider campaign.
GitHub's scheduled runs can be delayed. This website is separate from any existing ChatGPT automation.
